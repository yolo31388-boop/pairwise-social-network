# 游戏内玩家社群与社交网络系统

## 项目描述

游戏内玩家社群与社交网络系统的bug修复项目。核心模块 `social/network.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 社交网络构建完全没做玩家之间没有关系
- 影响力传播完全没做热门话题不能传播
- 社群发现完全没做不能发现玩家中的小团体
- 社群演化完全没做社群永远是同一个样子
- 推荐完全没做不能推荐好友和社群

## 运行测试

```bash
python -m pytest tests/test_social_network.py -q
```

修复目标：所有 14 个测试全部通过。
